Gerador de Números Aleatórios

Informe um valor numérico limite para gerar um número aleatório entre zero e o limite definido.

O número gerado estará no intervalo entre 0 e o valor informado (inclusivo).
Aplicação Java Web | JSF 2.3 • JPA 2.2 • Hibernate • Servlet Filter
